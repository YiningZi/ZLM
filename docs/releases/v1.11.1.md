# ZLM 1.11.1

当前推荐版本，最低支持 Blender 4.4.0。相对本地保留的 1.10.0：

- 增加 Blender 4.4+ 兼容，修正单位 API 及场景比例换算。
- 修复扩展加载后“关于与版权”面板的 `NameError: name 'bl_info' is not defined`；版本显示改用独立常量。
- 保留单指选环、多目标管理、仅影响相连项、平滑衰减和拓扑不变调整。
- 增加版本、界面 API、扩展面板和完整性回归测试。

## 安装

下载附件 `ZLM-1.11.1.zip`，通过 Blender **编辑 → 偏好设置 → 插件 → 从磁盘安装** 安装并启用。更新后请重启 Blender。不要将 GitHub 自动生成的源码 ZIP 当作安装包。

附件 `SHA256SUMS.txt` 可用于校验下载文件。安装包另带 GPL 许可证正文和文件完整性清单。

## 验证范围

原开发记录在 Blender 4.4.3 与 5.1.1 验证；本次仓库导入在 Windows 4.4.3 重新执行五组回归。GitHub Actions 另以 Linux 4.4.3 运行构建、回归与扩展校验。其他 Blender 版本尚未逐一验证。

## 使用注意

手掌只是示例，也适用于其他能形成有效截面的网格。相连衰减半径过大仍可能沿掌部影响邻指；开放截面的读数包含直线补齐段。调整不改变顶点、边、面及连接关系。
