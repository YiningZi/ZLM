# ZLM 1.10.0

本地保留的最早版本，作为 GitHub 历史起点。原开发记录日期为 2026-09-16；此次是历史归档。

- 按画线命中位置选环，适用于整手模型中的单根手指。
- 默认启用“仅影响相连项”，沿网格连接路径衰减。
- 支持多目标测量与局部围径调整，保留原网格拓扑。
- 修正透视投影、侧栏启动坐标和内部壳层定位。
- 调整不能达到目标围径时，取消并恢复原坐标。

附件 `ZLM-1.10.0-original.zip` 是原始安装包的直接归档，内容未改动。清单最低要求 Blender 5.2.0。原开发记录确认该版在 Blender 5.1.1 做过功能回归；作者于 2026-10-12 确认插件在 Blender 5.2 也已通过测试。日常使用推荐最新 4.4+ 兼容版本。
