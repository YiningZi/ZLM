# 使用指南

## 准备

从仓库 Releases 下载当前版本的 `ZLM-版本号.zip`，在 Blender 的“从磁盘安装”中安装。更新后重启。选中网格，在物体模式打开三维视图侧栏的 ZLM 标签。

先核对模型尺寸和场景单位。模型真实尺寸不正确时，只切换毫米/厘米显示不能解决问题。

## 测量

点击“新增测量目标”，按住左键横穿目标部位，线段中点尽量落在需要测量的表面，松开生成截面环。右键或 Esc 取消。

在整手模型上只横穿一根手指，避免一次跨过多个手指。画线方向决定截面方向；斜截面与正截面的周长不同。旋转视角核对环线是否贴合目标。

支持未封口模型。截面交线在边界处断开时会用端点间的直线补齐，数值包含补齐段，不能等同于缺失表面的实际曲线长度。

## 调整

选中列表项，输入目标周长（可直接输入 `62 mm`），选择衰减类型和半径，点击“调整当前目标”。调整后会重新测量；`Ctrl+Z` 可撤销。

| 参数 | 作用 |
| --- | --- |
| 目标周长 | 希望当前截面达到的尺寸 |
| 衰减半径 | 环线周围参与调整的范围；0 为自动估算 |
| 衰减类型 | 控制变形如何从环线逐渐过渡到未修改区域 |
| 仅影响相连项 | 沿网格连接路径计算距离，不直接跨越空间间隙 |
| 锁定截面法线 | 避免沿截面法线方向缩放 |

半径较小，变化更集中；半径较大，过渡范围更宽。手指仍通过手掌相连，半径过大可能影响其他手指。建议小幅、分步修改，并复核形状。

## 多目标

继续点击“新增测量目标”添加其他位置。列表项分别保存名称、目标周长和衰减参数。调整一个目标后，同一模型的其他目标会自动重测；范围重叠时，需要一起核对。

列表旁可定位目标模型、删除当前项或清空全部项。旧版选错位置的目标建议删除后重画。

## 故障排查

| 现象 | 建议 |
| --- | --- |
| 选中整块手掌或别的手指 | 移到指缝已分离的位置，缩短画线，让中点落在目标手指上 |
| 无法生成截面 | 检查选中的是网格、画线命中表面、截面方向和模型缺口 |
| 提示取消并恢复 | 增大衰减半径，分步小幅调整；检查修改器是否能映射原网格 |
| 更新后仍报 `bl_info` 错误 | 确认安装 1.11.1 或更高版本，重启 Blender，避免同时启用旧插件 |
| 显示文件完整性异常 | 使用官方 Release 重新安装；如自行修改源码，重新构建包和清单 |
| 侧栏不显示 | 选中网格，确认启用插件，在三维视图按 N，并切换 ZLM 标签 |

反馈时附 Blender 版本、ZLM 版本、步骤、完整报错和可公开的最小复现模型。不要上传机密工程、个人路径或凭据。
