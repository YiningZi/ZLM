# ZLM 1.10.0

Blender 网格围径测量与局部调整插件，作者 **Yining Zi**。

这是本地保留的最早安装包对应源码，作为仓库版本历史的起点。

## 功能

- 在模型上画线生成截面环，按画线命中位置选择目标手指。
- 支持多个独立测量目标及开放截面的端点补齐。
- 通过目标周长与衰减参数调整局部形状，保持顶点、边、面及其连接关系。
- 默认开启“仅影响相连项”，按网格连接路径计算衰减。
- 调整无法达到目标周长时取消操作并恢复坐标。
- 提供 SHA-256 文件完整性检查、作者和版权信息。

## 版本注意事项

原始安装包的清单要求 Blender 5.2.0。保留原始清单，不修改历史版本的兼容性声明。推荐日常使用后续的 Blender 4.4+ 兼容版本。

“仅影响相连项”不代表绝对隔离手指；半径过大时影响仍可沿掌部传播。开放截面的周长包含端点间的直线补齐长度。
